Redstone taught me more about logic gates than school did. This project turns that into a small web app.

## Features

- Place wires, torches, repeaters and lamps on a grid
- Step through the simulation one tick at a time
- Save and share circuits as a URL

<Tip variant="redstone">
  Signals weaken by one level per block, just like in the game. Repeaters reset them to full strength.
</Tip>

## Tech

Rendering uses a single HTML canvas. The simulation runs on a fixed tick in a web worker so the UI never stutters.
