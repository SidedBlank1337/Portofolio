Sunny and 25°C? That's a plains day. Snowing? Welcome to the snowy slopes.

## Features

- Seven-day forecast from a public weather API
- Each day is matched to a biome and its colours
- Temperature and rain charts

## Tech

Built with React and a small chart library. The API key stays on a serverless function so it never reaches the browser.
